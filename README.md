# 疾控汇总发布安全审查台

疾控数据员在公开「分区 × 年龄组」汇总检出数前，用本工具审查：**多份已公开汇总叠加后，是否会暴露小样本格（原检出数 1~4）的取值**。技术栈：FastAPI + SQLite + z3-solver。

## 快速开始

### Docker Compose（推荐）

```bash
docker compose up --build
```

访问：
- 内部审查台：http://localhost:8000/
- 公开页：http://localhost:8000/public

SQLite 库文件保存在命名卷 `app_data`（容器内 `/data/app.db`），重启后公开记录保留。

### 本地运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

库文件默认在 `./data/app.db`，可用环境变量 `DB_PATH` 覆盖。

### 自测

```bash
.venv/bin/python tests/selftest.py   # 32 项关键功能检查
```

## 演示流程（内置示例数据）

示例数据（`sample_survey.csv`，2 分区 × 2 年龄组，人数均 10）：

| 分区 | 年龄组 | 人数 | 检出数 |
|---|---|---|---|
| 城东 | 青年 | 10 | **2**（受保护小样本格） |
| 城东 | 老年 | 10 | 8 |
| 城西 | 青年 | 10 | 8 |
| 城西 | 老年 | 10 | 8 |

1. 打开内部台 `/`，点「导入示例数据」（导入后不可更换）。
2. 勾选「城东」+ 两个年龄组 → 预览（总数 10，安全）→ 确认发布。
3. 勾选两个分区 +「老年」→ 预览（总数 16）：单独看本安全，但与已发布的「城东」合并后，
   格「城东/青年」被约束到 **[0, 4]**（`城东合计10 − 城东老年≤10 ⇒ 城东青年≤4`，
   且 `老年合计16 ⇒ 城东老年≥6 ⇒ 城东青年≤4`），不再保留「≥5」的可行解 → 审查不通过。
4. 点「确认发布」→ 按最新公开记录重核，返回 409 并列出受影响格与可行范围。
5. 改发「青年」（总数 10）：与已公开记录合并仍安全 → 发布成功。
6. 打开公开页 `/public`：只有人数表与获准汇总，无格内检出数。

## 安全模型

- 未知量：每格一个整数 `x_i`，约束**仅**来自
  1. 界限 `0 ≤ x_i ≤ 人数_i`；
  2. 历次公开记录：所选交集格之和 = 公开总数；
  3. 候选发布：所选交集格之和 = 候选总数。
- 判定：对每个原检出数为 1~4 的格，须同时存在 `x_i = 0` 与 `x_i ≥ 5` 的可行整数解，
  否则拒绝并给出该格可行范围（z3 Optimize 求 min/max）。
- 确认发布时在全局发布锁内**重读最新公开记录并重核**，随后单事务写入：
  两个各自安全、合并不安全的窗口不会都被发布；保存失败整体回滚，不留半次发布。
- 求解在工作线程执行（每评估独立 z3 Context，线程安全），求解期间公开页与其他发布可用。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/import` | 导入调查 CSV（multipart，仅一次，导入后不可更换） |
| GET | `/api/admin/state` | 内部状态（含格内检出数） |
| POST | `/api/preview` | `{districts, age_groups}` → 交集总数 + 安全评估 |
| POST | `/api/publish` | 重核后发布；不安全返回 409 + 受影响格与可行范围 |
| GET | `/api/public` | 公开数据：仅人数与获准汇总 |

CSV 表头：`分区,年龄组,人数,检出数`（亦兼容 `district,age_group,population,detected`）。
校验：≤16 格；人数 ≥5；检出数为 0~人数整数；（分区,年龄组）唯一。

## 已知限制

- 未实现认证/授权：内部台与接口对任何可达者开放，生产部署须自行加访问控制。
- 发布串行锁为单进程内锁；多副本部署需改为数据库级互斥（如 SQLite 单写已天然串行，但重核-写入的临界区需以事务或文件锁保证）。
- 审查基于精确整数可行域（z3），非差分隐私；它保证「小样本格不被公开信息钉死」，不量化其他泄露渠道。
